## 🛠 Technology Stack

- **Frontend:** Pure HTML5, CSS3, Vanilla JavaScript
- **Hosting:** AWS S3 Static Website Hosting
- **CDN:** CloudFront with Origin Access Control (OAC)
- **Domain:** Custom domain through Route 53
- **Performance:** Optimized assets, minimal dependencies

## 🔧 Infrastructure

### AWS Architecture
- **S3 Bucket:** Private bucket with OAC for security
- **CloudFront:** Global CDN for performance and caching
- **Route 53:** DNS management and domain routing
- **Certificate Manager:** SSL/TLS certificates for HTTPS
